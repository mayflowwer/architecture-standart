### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**
Опишите здесь нефункциональные требования и архитектурно значимые требования.

|**№**|**Требование**                                                                                                  |
| QA1 | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды.                              |
| QA2 | При этом все сервисы должны работать 24/7 и быть доступны в 99,9% случаев                                      |
| QA3 | в случае сбоев в ЦОД необходимо, чтобы сервисы интернет-банка были доступны и выдерживали требуемую нагрузку.  |
| QA4 | Лучше избежать прямой работы интернет-банка с API АБС в новом процессе.                                        |
| QA5 | Но нужно учитывать, что АБС может масштабироваться только вертикально из-за своей базы данных.                 |
