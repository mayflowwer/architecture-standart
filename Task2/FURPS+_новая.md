| Код | Требования                                                                                                                 | Комментарий  |
|-----|----------------------------------------------------------------------------------------------------------------------------|--------------|
| F   | Функциональные (Functionality)                                                                                             |              |
| F01 | На сайте новый клиент видит список доступных депозитов с актуальными ставками.                                             | 
| F02 | Клиент подает заявку на услугу, заполняет ФИО и контактный телефон. С ним связывается менеджер call-центра.                |        
| F03 | На первом этапе менеджер бэк-офиса подтверждит заявку на депозит клиента.                                                  |
| F03 | Клиент видит список доступных депозитов и список персональных ставок.                                                      |              |
| F04 | Клиент указывает счет, сумму депозита и создает заявку на депозит. Клиент подтверждает действие через смс-код.             |              |
| F05 | Ставки по депозитам ведутся в банковской системе. К ним имеют доступ сотрудники бэк-офиса кредитного и депозитного отделов.|          

| U   | Удобство использования (Usability)                                                                                         |              |
| U01 | Интерфейс работы будет максимально удобным для клиента.                                                                    |              |
| U02 | Пользователи при работе должны видеть привычные цвета и брендированные элементы.                                           |              |
        
| R   | Надёжность (Reliability)                                                                                                   |              |
| R01 | Киент должен получить СМС-уведомления после подтверждения размера ставки и открытия депозита.                              |              |
| R01 | Новый клиент обязан пройти первичную идентификацию.                                                                        |              |
| R02 | Данные клиентов обязаны передаваться и храниться в шиврованном виде.                                                       |              |
| R03 | Данные, кот. передаеются из интернет-банка должны передаваться в шиврованном виде.

| P   | Производительность (Performance)                                                                                           |              |
| P01 | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды.                                          |              |
| P02 | При этом все сервисы должны работать 24/7 и быть доступны в 99,9% случаев                                                  |                    | 
| P04 | в случае сбоев в ЦОД необходимо, чтобы сервисы интернет-банка были доступны и выдерживали требуемую нагрузку.              | арх.-значимое тр.  |

| S   | Поддерживаемость (Supportability)                                                                                          |                    |
| S01 | Также нужно предусмотреть разработку документации для дальнейшего расширения системы.                                      |                    |
| S02 | Лучше избежать прямой работы интернет-банка с API АБС в новом процессе.                                                    | арх.-значимое тр.  |
| S03 | Лучше предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД|                    |
| S04 | Но нужно учитывать, что АБС может масштабироваться только вертикально из-за своей базы данных.                             | арх.-значимое тр.  |

| +R  | + Ограничения (Restrictions)                                                                                               | арх.-значимое тр.  |
| +R01| Функционал работы с СМС реализован в ядре системы.                                                                         |              |
| +R02| При доработках во всех системах нужно как можно больше использовать технологии, которые уже есть в банке.                  |              |
| +R03| Также нужно придерживаться системы дизайна для приложений, которая принята в компании.
